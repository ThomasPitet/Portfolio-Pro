MotorFest

Application web de catalogue, consultation et comparaison de véhicules avec graphiques radar et gestion de favoris.

Présentation du projet

MotorFest est une application web développée avec Node.js, Express, MySQL et EJS. Elle permet aux passionnés d'automobile et de jeu vidéo de consulter un catalogue complet de véhicules, d'analyser leurs performances détaillées via des graphiques radar interactifs (Chart.js), de comparer plusieurs modèles côte à côte et de sauvegarder leurs favoris.

Le projet est structuré selon un pattern MVC strict (Modèles, Vues, Contrôleurs, Routeurs) avec validation des formulaires par Zod et gestion de sessions utilisateurs sécurisées.

Node.js Express.js MySQL EJS Tailwind CSS Chart.js Zod MVC

Fonctionnalités principales

  • Catalogue Catalogue complet de véhicules filtrable
  • Radar Graphiques radar de performance (Chart.js)
  • Compare Comparateur côte à côte de véhicules
  • Favoris Gestion des favoris (LocalStorage & Serveur)
  • Auth Inscription & Connexion (Session Cookie)
  • Filtres Filtres par catégorie, marque, période & stats
  • MVC Architecture MVC & Base MySQL
  • Zod Validation des données avec Zod
